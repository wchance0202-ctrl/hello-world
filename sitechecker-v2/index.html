01独立评估

安全可放心运行，判定口径保守：适合做“初筛”，“是”的结论可信，“待确认”需人工复核

评估基于源码通读、SHA-256 校验与同版本工具链交叉编译比对。工具检测的是“需要境外出口才能打开”的网址，本身不提供翻墙能力，也不会自动判断你当前是否开着 VPN。

安全与隐私 · 良好

源码与二进制一致，仅监听本机，无遥测

4 个可执行文件用 go1.27.3 + -trimpath -ldflags "-s -w" 重新编译，哈希完全一致；服务只绑定 127.0.0.1 随机端口 + 随机令牌路径，并校验 Host / Origin；代码中没有任何上报地址。

判定方法 · 严谨

误报低：只有“3 次网络失败 + 2 次连续成功”才算目标

HTTP 错误、验证码、证书异常、空页、错误页一律“待确认”，不强行算作打不开；两轮间隔超过 30 分钟还会要求重测大陆。TLS 证书校验始终开启。

覆盖与验证 · 有缺口

漏报偏多，且未在真实大陆线路与真机上实测

DNS 污染、iOS 握手阶段重置等典型阻断形态可能落入“待确认”；大批量全超时清单会触发 30 分钟规则；VPN 状态与出口位置只依赖使用者勾选确认。

需要留意的发现：多数会造成“漏报”（真被拦截却显示待确认），而不是误报

较高

iOS：握手阶段被重置可能归为“证书异常”

基于 SNI 的阻断在 TLS 握手中发 RST，iOS 常报 -1200 “安全连接失败”。脚本把 -120x 一律归为 TLS / 证书异常 → 待确认，这类网址在 iOS 端可能进不了目标列表。

建议在 iOS 端区分证书校验失败与握手中断；使用时对“证书异常”行在桌面端复测。
中

DNS 污染可能被识别为证书问题

被污染的域名若解析到一个恰好开放 443 的无关 IP，会得到“证书主机名不匹配”，结论是待确认而非“大陆打不开”。程序没有做 DNS 对照。

建议增加 DoH 解析对照；或把“大陆证书异常 + 境外正常”单列为疑似项。
中

30 分钟规则与大批量超时清单冲突

每条全超时网址大陆阶段约 3×12 秒 + 退避 ≈ 38 秒，6 并发下约 280 条就要 30 分钟。清单靠前的行会被标“需更新大陆检测”。

建议每批控制在 200 条以内；使用显式代理时勾选“直连复测”；或把超时调到 6–8 秒。
中

网络状态只靠勾选确认

程序不检测出口 IP 归属，也无法发现 TUN / 全局 VPN 是否真的关闭。若测大陆时忘关 VPN，整批结果都会失真。

建议每轮填写“已知能打开的检查网址”，并先用 2–3 条已知结果的网址试跑。
低

非浏览器 User-Agent

请求标识为 SiteChecker/2.0，部分站点的 WAF 会直接返回 403 或验证页，两边都显示待确认。

建议属于有意的透明做法；遇到大量 403 时人工在浏览器里抽查。
低

未签名、未在真机实测

Windows 会出现 SmartScreen 提示，Mac 需手动允许；作者说明 Windows / Mac / iPhone / 安卓与大陆线路均未实测。

建议先核对本页 SHA-256，再小批量试跑。
02判定口径

先测大陆，再测境外：只有两边证据都完整，才给出“大陆打不开、境外可打开”

检测的是输入的具体 URL，不扫描全站、不登录、不点击、不测下载。结果只代表本次线路、所选出口和时间，不能据此认定封锁原因。

04使用说明

四步完成一次对照：准备清单、大陆检测、境外对照、筛选导出

手机端测的是手机自身的 Wi-Fi / 移动网络，不需要电脑，也不使用云端服务器代测。

01

准备清单

粘贴网址或导入 UTF-8 TXT，一行一个。桌面单批上限 5000 条，建议每批 ≤ 200 条。

02

大陆检测

关闭代理、VPN 与 TUN，使用大陆网络；勾选确认后开始。期间不要切换网络。

03

境外对照

开启境外全局出口，选择系统代理 / 手动代理 / 全局 VPN·TUN 并确认。大陆已能打开的自动跳过。

04

筛选导出

筛选“大陆打不开、境外可打开”，导出简表或详细 CSV。退出程序前务必导出。

06常见问题

使用前值得知道的几件事

程序会上传我的网址清单吗？

不会。源码中没有任何上报地址，检测在本机进行；但目标站点、你的代理和网络服务提供方仍能看到这些请求。桌面 / 安卓结果只存在内存里，iOS 保存在 Scriptable 本地目录。

它能判断我当前是否开着 VPN 吗？

不能。程序无法从进程内绕过系统 VPN / TUN，也不验证出口所在地，全靠每轮开始前的勾选确认。建议在“已知能打开的检查网址”中填写一个只有境外才能打开的地址作为连通检查。

为什么有很多“待确认”？

这是有意的保守设计：除纯网络失败外，其余异常都不强行算作打不开。若大量出现“证书异常”，可能是 DNS 污染或握手被重置，请在桌面端复测或人工抽查。

一次能测多少条？要多久？

桌面 / 安卓单批最多 5000 条，iOS 最多 100 条。能打开的网址很快完成；打不开的网址每条约需 38 秒（默认 12 秒超时 × 3 次）。为避免触发 30 分钟规则，建议每批不超过 200 条。

Mac 提示“无法验证开发者”怎么办？

本包未做 Apple 公证。先核对本页 SHA-256，再到“系统设置 → 隐私与安全性”选择“仍要打开”。不要单独移动启动文件。

超时应该设置多少？

可设 2–60 秒，默认 12 秒。清单以被拦截网址为主时可调到 6–8 秒，以缩短整批耗时；网络较差时保持默认。
