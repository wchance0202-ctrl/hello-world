# 分镜表

- 音乐：合成，120 BPM，4/4 拍，1 拍 = 0.5 秒，1 小节 = 2 秒；全片 31 秒（930 帧，30fps）。
- 所有时间都从 `beats.json` 读取。拍号从 0 开始数，第 i 拍 = i × 0.5 秒，每小节第 1 拍是强拍。
- 卡拍规则：转场在拍点前的窗口里先慢慢预备（只走 15–22%），最后 5 帧猛加速，拍点那一帧走到 97%，之后 4 帧缓冲走完剩下的 3%。
- 全片只用一套缓动：指数族，参数在 `CONFIG.ease` 里。
- 画面语言：所有事件都是同一套 420 个 3D 粒子组成的立体图形，前一件事的粒子变形成后一件事。
- 质感层：粒子加法混合加光晕、透视地面网格（时间轴是地面前沿，镜头横移时近快远慢）、背景巨型描边年份、前景虚化光斑、胶片颗粒和暗角。
- 舞台背后有一盏光源，颜色随音乐能量从冷蓝走向琥珀。

## 音乐四段（music.py）
- **起（0–8 秒）**：钢琴和弦加简单旋律，铺底 pad，力度逐小节增大。
- **承（8–18 秒）**：底鼓先打 1、3 拍，12 秒起每拍都打；加入踩镲、贝斯，14 秒起加拍手；钢琴改成 8 分音符分解和弦。
- **蓄（18–24 秒）**：军鼓按 4 分 → 8 分 → 16 分音符逐步加密；白噪声扫频加音高上升；23.5 秒鼓全停，只剩上升音和反向镲。
- **爆（24–28 秒）**：drop 加入全部乐器，包括重底鼓、拍手、踩镲、超锯齿和弦、侧链贝斯、主旋律、镲片和次低频冲击。
- **尾（28–31 秒）**：C 大调收尾和弦，余音 3 秒。

每小节响度（RMS）：0.040 → 0.058 → 0.060 → 0.076 → 0.122 → 0.128 → 0.162 → 0.168 → 0.173 → 0.181 → 0.183 → 0.208 → 0.227 → 0.228，到 drop 后的最后一小节都是单调上升；之后是收尾余音。

母带：轻度饱和后按 BS.1770 标准化到 −14 LUFS（视频平台的常用响度），峰值约 −1.6 dBFS。
